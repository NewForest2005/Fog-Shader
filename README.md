# Fog Shader

Demo de niebla 3D con p5.js y GLSL.

## Ejecutar

### Windows

```bat
run.bat
```

### macOS / Linux

```bash
python3 -m http.server 8000
```

Abrir:

```text
http://localhost:8000
```

## Controles

- `Fog Near`: distancia donde empieza la niebla.
- `Fog Far`: distancia donde termina la transición.

## Archivos

- `index.html`: entrada.
- `script.js`: escena 3D y shaders.
- `style.css`: estilos.
- `assets/f-texture.png`: textura.
